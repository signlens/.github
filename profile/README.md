# SignLens

**See what a Solana transaction does before you sign it.**

SignLens is a browser extension that sits between a dapp and your wallet.
Each transaction a site asks you to sign is explained in plain words first:
what leaves your wallet, where it goes, what it is for, and what looks wrong.
Then the exact same transaction goes to your own wallet (Phantom, Backpack,
Solflare), which asks you as usual. SignLens holds no keys and signs nothing.

- [Install](https://signlens.dev/install) for Firefox or Chrome
- [How it works](https://signlens.dev/how-it-works)
- [Privacy](https://signlens.dev/privacy): in this beta the explanation is computed by SignLens's server
- Security issues: security@signlens.dev ([policy](https://github.com/signlens/signlens-extension/security/policy))
